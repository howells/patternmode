# Web App Tests

This directory contains all tests specific to the web application (documentation/playground site).

## Structure

- `components/` - Unit tests for web app specific components and utilities
- `e2e/` - End-to-end tests using Playwright
- `screenshots/` - Screenshots generated by e2e tests
- `setup/` - Test setup and configuration files

## Running Tests

From the root of the monorepo:

```bash
# Run all web app tests
pnpm test

# Run only unit tests
pnpm test:run

# Run e2e tests
pnpm test:e2e

# Run tests with UI
pnpm test:ui
pnpm test:e2e:ui
```

From the web app directory (`apps/web`):

```bash
# Run unit tests
pnpm test

# Run e2e tests
pnpm test:e2e
```

## Configuration

- `vitest.config.ts` - Vitest configuration for unit tests
- `playwright.config.ts` - Playwright configuration for e2e tests
- `setup/vitest.setup.ts` - Vitest setup file
