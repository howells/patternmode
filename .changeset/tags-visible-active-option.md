The Tag Selector's active option is now easy to see. It used the same `--muted` fill as hover, about 1.1:1 against the popover, and it's the only focus indicator keyboard users get in the list. It now uses the theme's `--accent` fill and `--accent-foreground` text, with an inset hairline in `--ring` that measures 7.6:1 against the popover. Hover keeps the quieter `--muted` fill.
